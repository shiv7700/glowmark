02Why

Ink stays ink. Glow sits on top.

Most highlighters rewrite your markup with <mark> and <span>. glowmark asks the browser to paint the matches instead, so your HTML is exactly what you rendered.

  • No DOM changes

    Painted with the CSS Custom Highlight API.

  • Any framework

    One function. React, Vue, Svelte, Angular, none.

  • Search built in

    words() escapes and ignores case for you.

  • Hover, tap, keyboard

    One shared tooltip, opened however people read.

  • Follows edits

    Re-renders and typing update on their own.

  • Tiny

    2 kB gzipped, typed, zero dependencies.

03Use

Render as usual. Then point.

Call it once on the element that holds your content. It returns a function that undoes everything.

import { glowmark, mustache } from 'glowmark';
import 'glowmark/style.css';

const destroy = glowmark(element, [
  mustache({ tooltip: (m) => `Variable: ${m.groups[0]}` }),
]);
