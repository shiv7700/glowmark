glowmark

Highlight search terms, {{variables}} or any pattern in your content, with tooltips. Your HTML is never changed. Zero dependencies, any framework.

npm install glowmark
GitHub npm

Try it

Hi {{ user.name }}, your order #${orderId} ships on {{ delivery.date }}.

Questions about your order? Reply to this email. TODO: confirm the {{ support.email }} address.

Hover a highlight to see its tooltip. The text is editable, so type a new {{ variable }} and watch it light up.

The actual HTML: no <span>, no <mark>


      


      
Use it

      
import { glowmark, mustache, words } from 'glowmark';
import 'glowmark/style.css';

const destroy = glowmark(element, [
  mustache({ tooltip: (m) => `Variable: ${m.groups[0]}` }),
  words(['order', 'confirm']),
]);


      
Why glowmark

      
    
        
  • Your DOM is never touched. Matches are painted by the browser's CSS Custom Highlight API, so React, editors and your own code are never surprised.
    • 
        
  • Any framework, or none. One function that attaches to an element.
    • 
        
  • Follows your content. When the content re-renders or is edited, the highlights update on their own.
    • 
        
  • Tiny. About 1.7 kB minified and gzipped, with zero dependencies.
    •
