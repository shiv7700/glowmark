glowmark

Highlight search terms and {{ variables }} in any content.

Your HTML is never changed. Works with any framework.

Try it GitHub
Documentation
  • No DOM changes
  • Any framework
  • Search built in
  • Hover tooltips
  • Follows edits
  • TypeScript

Installation

One package, no dependencies.

npm install glowmark

Usage

Render your content as usual, then point glowmark at the element.

import { glowmark, mustache } from 'glowmark';
import 'glowmark/style.css';

const destroy = glowmark(element, [
  mustache({ tooltip: (m) => `Variable: ${m.groups[0]}` }),
]);

Try it

Pick a rule. Hover a highlight for its tooltip. The text is editable.

Hi {{ user.name }}, your order #${orderId} ships on {{ delivery.date }}.

Questions about your order? Reply to this email. TODO: confirm {{ support.email }}. FIXME: add a tracking link.

Your HTML stays the same

This is the live HTML of the text above. No <span>, no <mark>, even while you edit.
